# Alumni Connect

## About the Project

Alumni Connect is a web-based platform that helps students and verified alumni stay connected and share useful opportunities.

The platform allows students to find alumni, explore career opportunities, and participate in webinars. Alumni can create verified profiles and share job and internship opportunities with students.

## Features

- Student and alumni login
- Verified alumni profiles
- Search and view alumni profiles
- Job and internship opportunities
- Webinars and events
- Role-based access
- Forgot password with OTP
- Secure authentication using JWT and bcrypt
- Admin management of users and content

## User Roles

### Student
- Login to the platform
- Search for alumni
- View alumni profiles
- Explore job and internship opportunities
- View webinars

### Alumni
- Create and manage a profile
- Share job and internship opportunities
- Participate in webinars

### Admin
- Verify alumni
- Manage users
- Manage and remove inappropriate content

## Technologies Used

- HTML, CSS, JavaScript / React
- Node.js
- Express.js
- MongoDB
- JWT
- bcrypt
